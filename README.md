# Rock Paper Scissors...SHOOT!
## This is a simple and straightforward web-based Rock Paper Scissors rendition using HTML/CSS/Javascript.

This exercise started as a basic console text-based game to get used to the feel of programming in vanilla Javascript. The latest push adds a dark-friendly UI so you can play the game strictly on the page v. in the Dev. Tools.

Concepts practiced:
 - Variables (being mindful of scoping)
 - Functions (with returns)
 - A simple, no-frills CSS setup with Flexbox to keep things tidy
 - Event Listener to key off of button clicks
 - DOM manipulation to add the results to the page
